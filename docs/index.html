go-rmodel-pipeline

Go-orchestrated pipeline for training, evaluating, and validating R machine learning models with threshold-based quality gates.

View on GitHub

How it works

go run main.go
    │
    ├── Rscript r/train.R           trains model, saves r/model.rds
    ├── Rscript r/evaluate.R       evaluates on test set
    ├── Rscript r/export_metrics.R writes metrics.json
    │
    └── Go validates thresholds → exit 0 / exit 1

Getting started

1
Clone the repository git clone https://github.com/llerandi/go-rmodel-pipeline.git && cd go-rmodel-pipeline
2
Download Go dependencies go mod tidy
3
Install R packages (once) Rscript -e 'install.packages(c("tidymodels", "ranger", "modeldata", "jsonlite"))'
4
Add your data Edit r/train.R to load your own dataset.
5
Adjust thresholds Edit config.yaml, or override at runtime with --roc-auc, --accuracy, --f-measure flags.
6
Run the pipeline go run main.go

Quality gates

If any metric falls below its threshold, the pipeline exits with code 1 - suitable as a CI/CD gate.

MetricThreshold
ROC-AUC≥ 0.80
Accuracy≥ 0.75
F-Measure≥ 0.70

Customisation

Swap the dataset Edit r/train.R to load your own data.
Change thresholds Edit config.yaml, or override at runtime with --roc-auc, --accuracy, --f-measure flags.
Add metrics Extend the Metrics struct in main.go and the export in r/export_metrics.R.
